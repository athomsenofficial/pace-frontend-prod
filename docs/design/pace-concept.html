1 · Design direction

Paper, harbor and hairlines

Both of Drew's sites already share one system: warm paper, near-black ink, 1px hairlines, 4px radius, one accent, a serif used only for titles, and a sans for everything you read or click. PACE takes that frame as-is and gives it an official tone. Harbor navy-teal replaces default Tailwind indigo, and five muted status colours replace the rainbow tiles. Every decision serves scanning a 400-row roster quickly.

From MTL Services

mtl-services/platform/src/app/globals.css · components/ui/* · shells/app/*

  • Neutral scale, unchanged. paper #F4F1EA, surface #FFFFFF, surface-2 #EAE5DA, line #D8D2C6, line-strong #B9B1A2, ink #14181C / #3A4046 / #5F656C.
  • Harbor #0E2A35 / #173E4D becomes the PACE primary. It reads as Air Force navy without the SaaS indigo. Focus ring #1F6F8B.
  • Status hues: palm #2F6B4F → Eligible, brick #A8362E → Ineligible, brass #B8862B + brass-ink #7E5B1C → Discrepancy.
  • Type: Newsreader 400 (titles only), Instrument Sans 400/500/600 (UI, 15px/1.5 app surface), tabular numerals. IBM Plex Mono comes from MTL's earlier web/app/layout.tsx and is used only for codes (PAS, AFSC, SRID).
  • Components: Button (40px app, radius 4, hover changes colour only, one primary per view). Field (label above, 13px error below, aria-describedby). Table (TH on surface-2, 12px caps +0.08em, hairline rows). Tag (8px dot pill, the only round shape). Badge (square caps). Tabs (2px underline + count). 248px side-nav app shell.

Left out: clay #B65A32 as CTA. It is too warm and too close to brick for a status-heavy screen.

From Hollow Root

hollowroot/platform/src/app/globals.css · components/ui/*

  • Status tints: sage-tint #E1E7DC (Eligible ground), rose-tint #F1E3E1 (Ineligible / PII ground). Each carries text at 5:1 or better.
  • Stone #8B7B6E as the input border (HR's "line-strong → UI borders only", 3.6:1 on paper). MTL's input border #D8D2C6 is under 3:1, so PACE uses this one. Stone also marks Small Unit; stone-ink #5E5148 carries its text.
  • The admin-workspace rule: HR's .admin-ui drops the serif and keeps one brand accent. PACE does the same inside tables and forms and keeps the serif for page titles.
  • Linen weave (the .linen CSS texture) on the upload drop area: a quiet surface instead of a dashed box or an illustration.
  • Discipline: every colour pair carries a measured contrast note, fills that are never used as text, a prefers-reduced-motion kill switch, and eyebrow caps for section labels.

Left out: Cormorant Garamond + Figtree (too soft for a USAF tool), dusty rose / gold foil as accents, the 48px "Book" CTA, scroll-reveal motion.

Rules

  • Radius4px controls and buttons, 8px panels / tables / dialog. 999px only on the status Tag.
  • ElevationNo shadows on cards. Hairline borders do the separation. The only shadow is the dialog (shadow-1).
  • AccentOne primary (harbor) button per view, always the next step. Everything else is outline, underline, or a 28px row action.
  • MotionColour transitions only, 120ms. No pulsing, scaling, or staggered step animations.
  • WordsPlain-language reason first; the engine's raw code underneath in mono, for traceability.
  • DatesAlways DD-MMM-YYYY (01-FEB-2023), typed into text fields. No native date pickers.

  1. 1Summary bar replaces the six icon-bubble stat tiles. It says what to do ("3 discrepancies to review") and links filter the table. It also warns when edits haven't been re-processed, so Re-process stops being a mystery button.
  2. 2Category tabs carry the counts (one place, not two). "Review" flags the category that needs a decision. Search, unit filter and "Only my changes" sit on one 36px toolbar. Try the tabs and the / key.
  3. 3Reason in plain words first, with the engine's own string underneath in mono (TIG: < 6 months, UIF code: 3) so admins can trace it to the rule. Missing dates print as "Missing" in red in their own column.
  4. 4Override: a square OVERRIDE badge, a 3px harbor edge on the row, the original category and the reason shown in the row, and an "Undo move" action.
  5. 5Move to eligible opens inline under the row (no modal), focuses the reason field, and requires a reason. The confirm button is green outline, not a second primary.
  6. 6Rows are focusable. Arrow keys move between rows, E / M / Delete act on the focused row, and every action button has a full aria-label ("Move TESTGOLF, GREG H. to eligible"). Actions are always visible, not hover-only.
  7. 7The sticky action bar always shows Back, the one primary action, and the outstanding issue. Assumption to confirm with Drew: whether unreviewed discrepancies should block continuing.
  8. ·Upload Logo (today a big green button) moves to step 4 (Download), where the logo is actually used.
